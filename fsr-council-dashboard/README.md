# 대표FSR협의회 운영 대시보드

메트라이프 대표FSR협의회 운영 현황을 한눈에 볼 수 있는 웹 대시보드입니다.

## 주요 기능

- **대시보드** — 예산 집행률·잔여 예산·처리 대기 건의·다음 일정 KPI, 월별 집행 추이 차트, 최근 공지/건의, 협의회 구성
- **공지사항** — 분류(공지·행사·규정·일반)·상단 고정 지원, 운영진 모드에서 공지 작성
- **건의함** — 건의 제출(익명 가능), 상태 필터(접수·검토중·답변완료·보류), 공감, 운영진 답변·상태 변경
- **예산·결산** — 재원/집행/잔액 요약, 항목별 집행 미터, 결산표, 월별 집행 차트(표 전환 가능), 지출 내역 필터, 운영진 지출 등록
- **회의·일정** — 다가오는 일정(D-day)과 안건, 지난 회의록 요약

라이트/다크 모드(시스템 설정 추종), 모바일 반응형을 지원합니다.

## 실행 방법

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

## 데이터에 대해

- 처음 열면 `src/data/seed.ts`의 **2026년 데모 데이터**가 표시됩니다.
- 화면에서 등록한 공지·건의·지출은 **브라우저 localStorage**에 저장됩니다(서버 없음). 사이드바의 "데이터 초기화"로 데모 상태로 되돌릴 수 있습니다.
- **Claude Artifact로 배포된 경우**(공유 문서 모드): `src/lib/artifactSync.ts`가 데이터를 페이지에 내장하고, 변경할 때마다 새 버전으로 게시해 **모든 열람자에게 공유**됩니다. 편집 권한이 없는 열람자는 자동으로 읽기 전용이 됩니다. 로컬 실행·정적 호스팅에서는 이 계층이 자동 비활성화됩니다.
- 실제 운영에 쓰려면 `seed.ts`를 협의회 데이터로 교체하거나, 이후 백엔드(API/DB)를 붙이면 됩니다. 데이터 접근이 `src/store.tsx` 한 곳에 모여 있어 교체가 쉽습니다.
- 데모의 인물·지점·금액은 모두 가상의 예시입니다.

## 기술 스택

- Vite + React 19 + TypeScript
- Tailwind CSS v4 (CSS 토큰 기반 라이트/다크 테마)
- react-router (해시 라우팅 — 정적 호스팅에서도 동작)
- 차트는 외부 라이브러리 없이 SVG로 직접 렌더링 (호버 툴팁·키보드 접근·표 뷰 제공)

## 운영진 모드

사이드바(모바일은 상단)의 **운영진 모드** 토글을 켜면 공지 작성, 건의 상태 변경·답변, 지출 등록 기능이 나타납니다. 프로토타입이므로 별도 로그인은 없습니다.
