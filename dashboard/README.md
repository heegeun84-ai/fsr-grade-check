# 2026 MetLife FSR 실적 정산기 (MPC / MDRT / PB2)

`index.html` 한 장짜리 계산기. 더블클릭으로 열리고, 기준수치 옆에
회사 전산에서 확인한 내 실적을 입력하면 등급·달성률·남은 금액이 바로 계산됩니다.

## 구성

- **MPC** — 현재 포인트 입력 → 잠정 등급 + 등급별 남은 금액
  (기본 기준: 2026 업적 달성기준 표 Top President 2억 ~ Bronze 7,000만.
  순위 컷·유지율 89%는 별도 충족 필요 문구로 안내)
- **MDRT** — NSC(FYC)·AGI 두 기준 각각 입력, 하나만 충족하면 레벨 인정
  (기본 기준: 회사 전산 달성 Grade 표, 천원 절사 → 원 환산.
  NSC 75,194,000 / 225,581,000 / 451,163,000 ·
  AGI 130,233,000 / 390,698,000 / 781,395,000.
  2027 기준 발표 시 '기준값 수정'에서 교체)
- **PB2** — 연도 블록 4개(기본 2024~2027, 연도 자체가 입력값)에
  유지 SC·PB1 횟수 입력 → 일정액×가감률 책정액 계산.
  유지SC 100·150백만 보장(6·9회), 300백만 합산(+3회) 자동 반영.
  하단 "매년 1월, 받게 될 PB2" 타임라인은 입력한 연도에서 지급 연도를
  자동 도출해 연도분 겹침(20%→30%→50%)을 합산. 올해·미래 연도분은
  '예상' 표기 (2027 예상치를 넣으면 2029.1이 완성됨)
- **기준값 수정** (하단 접이식) — 모든 기준액 편집 가능

## 자동 동작

- 제목 연도·연말 D-day는 접속일 기준 자동 표시
- MPC·MDRT의 미반영 월 입력(전월 마감·당월 현재)은 달이 바뀌면 자동 이월:
  1개월 경과 시 전월분→전산 합산·당월분→전월 칸, 2개월 이상이면 전부 전산 합산.
  이월 시 상단에 안내 배너 표시 (전산 조회값과 다르면 직접 수정)

## 데이터

입력값은 브라우저 localStorage에 자동 저장, 서버 전송 없음.
'전체 지우기'로 초기화. 이름/비번 저장 기능은 필요해지면 추가 예정.
