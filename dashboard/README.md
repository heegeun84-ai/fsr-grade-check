# 2026 실적관리 대시보드 (MPC / MDRT / PB2)

`index.html` 파일 하나로 동작합니다. 더블클릭해서 브라우저로 열면 끝이고,
설치나 서버가 필요 없습니다. 입력값은 그 브라우저의 localStorage에만 저장되며
외부로 전송되지 않습니다.

## 지금 들어가 있는 것

| 항목 | 값 | 출처 |
|---|---|---|
| MDRT 수수료 기준 | 67,873,100원 | 2026년 등록 기준(2025년 실적), 대한민국 |
| MDRT 보험료 기준 | 169,682,750원 | 위와 동일 |
| COT 배수 | 3배 | MDRT 공통 규정 |
| TOT 배수 | 6배 | MDRT 공통 규정 |

세 트랙(수수료 · 보험료 · 연간총수입) 중 **하나만** 충족하면 되고,
금액은 모두 **세후 수령액** 기준입니다.

## 확인이 필요한 것 (자료 주시면 반영)

### 1. MDRT
- [ ] **2027년 등록 기준액** — 이 대시보드는 2026년 실적을 관리하므로 실제 판정 기준은
      2027년 등록 기준입니다. 아직 미발표라 2026년 기준값을 임시로 넣어뒀습니다.
- [ ] **연간총수입(Income) 기준액** — 공식 문서를 열지 못해 비워뒀습니다.
      수수료 : 보험료 비율이 1 : 2.5로 미국 기준과 같은 점을 보면 1억 1,700만원 선으로
      추정되지만, 협회 공지로 확인이 필요합니다.
- [ ] 회사(메트라이프) 자체 인정 기준이 협회 기준과 다른지
- [ ] 성적 산정 기간이 역년(1/1~12/31)인지 회사 회계연도인지
- [ ] 본인·배우자·부양가족 계약 5% 초과분 제외 규정의 실제 적용 방식

### 2. MPC
- [ ] 정식 등급 체계와 등급명 (지금은 MPC / 실버 / 골드로 임시 입력)
- [ ] 등급별 기준 금액
- [ ] 환산성적 + 보너스 합산이 맞는지, 보너스 인정 범위
- [ ] 집계 주기 (연 단위 / 분기 / 반기)
- [ ] 유지율·건수 등 금액 외 부가 조건

### 3. PB2
- [ ] 기준 금액
- [ ] 환산성적에서 **제외되는 항목** 목록 (지금은 제외 반영 후 금액을 직접 넣는 구조)
- [ ] 승급/유지 조건이 나뉘는지

### 4. 공통
- [ ] 상품별 환산율 표 (종신 / 정기 / CI / 건강 / 연금 / 변액 등)
- [ ] 13회차·25회차 유지율 기준이 판정에 들어가는지
- [ ] 회사 전산 실적 다운로드 파일 양식 샘플 — 있으면 붙여넣기 자동 파싱을 붙일 수 있습니다

## 화면 구성

- **히어로** — MDRT 달성률(가장 유리한 트랙 자동 선택), 목표까지 남은 금액, 월 필요액
- **스탯 타일 3개** — MPC / MDRT / PB2 각각의 달성률·잔여액·월 필요액·연말 예상
- **MDRT 미터** — 트랙별로 MDRT / COT / TOT 임계선을 한 축에 표시
- **누적 vs 필요 페이스** — 실적선은 입력된 마지막 월까지만 그림
- **월별 환산성적** — 환산성적 위에 보너스를 쌓은 컬럼
- **월별 실적 입력** — 회사 전산 수치를 그대로 입력, 자동 저장
- **기준값 설정** — 확정 기준 받으면 여기만 고치면 전체가 다시 계산됨
- **표로 보기** — 차트의 모든 값을 표로 (색에만 의존하지 않도록)

## 데이터 백업

`JSON 내보내기`로 현재 데이터를 클립보드에 복사해 텍스트 파일로 보관하고,
`불러오기`로 그 파일을 다시 넣을 수 있습니다. 브라우저 캐시를 지우면
localStorage도 함께 지워지니 주기적으로 내보내 두세요.
